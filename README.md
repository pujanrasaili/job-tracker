# 🚀 Job Application Tracker

A full-stack web application to track your job applications, built with Python Flask, SQLite, HTML, CSS and JavaScript.

## ✨ Features

- ➕ Add job applications with company, role, location, date, status and notes
- 📊 Dashboard with stats (Total, Applied, Interview, Offer, Rejected)
- 🔄 Update application status with one click
- 🗑️ Delete applications
- 🌐 Link to job posting URL
- 🎨 Beautiful dark themed UI

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript
- **Version Control:** Git & GitHub

## 🚀 How to Run

1. Clone the repository
   `git clone https://github.com/pujanrasaili/job-tracker.git`

2. Navigate to the folder
   `cd job-tracker`

3. Create virtual environment
   `python -m venv venv`
   `venv\Scripts\activate`

4. Install dependencies
   `pip install flask`

5. Run the app
   `python app.py`

6. Open browser and go to `http://127.0.0.1:5000`
